# Changelog

## 0.1.0 (2026-10-13)

First release.

* The eight asymmetric association measures of the thesis, plus Conviction
  with a consistent orientation.
* Document co-occurrence index to replace Web hit counts, saved as plain
  `.npz` files.
* InfoSimba, AIS and AISs, with three ways of normalising AISs.
* The generality decision rule for sentence pairs and for words, including
  attributional profiles.
* The three pre-processing levels, a multiword-unit merger and a LocalMaxs
  extractor.
* Loaders for the RTE and ASSIN XML formats.
* A seven-step reproduction pipeline with pinned data, and the reference
  results it produces.
